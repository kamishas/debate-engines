# Genuine sample runs

These directories contain real Anthropic responses, including failed attempts. They are not synthetic fixtures.

Start with:
- [Right contact](right-contact/final.json): capped after 3 rounds; partial report with disputes.
- [Engagement history](engagement-history/final.json): completed after 3 rounds.
- [Cold relationship](cold-relationship/final.json): completed after 3 rounds.

Every directory contains actual exchanges.jsonl, transcript.md, input.json, and metadata.json. final.json exists only when reporting succeeded. Failure directories preserve errors and partial reports as recorded. [Evaluation and known fidelity issues](../EVALUATION.md) distinguishes structural validation from semantic review.

Confidence values are self-reported judgments. Completed means ready to document, not approved for implementation.
